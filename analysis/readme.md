# Statistical Analysis and Machine Learning Experiments

## Overview

This folder contains all **statistical analysis, machine learning experimentation, and modelling workflows** used in the Education Planning Dashboard project.

The work here focuses on developing, evaluating, and validating models before their outputs are integrated into the production services found in the `main` project folder.

The primary objectives of this directory are:

- Developing **time series forecasting models**
- Performing **Time series analysis for time series forecasting methods**
- Building **similarity matching models for occupation recommendations**
- Experimenting with **machine learning approaches for time series clustering and NOC occupation matching**
