# Education Planning Dashboard – Project Repository

## 📦 Overview

This repository contains the full implementation of the **Education Planning Dashboard**, a system designed to assist users in exploring educational pathways, career outcomes, and labour market trends using data-driven insights and AI.

The project is divided into two primary components:

| Folder | Purpose |
|------|------|
| **main** | Contains the production application, including microservices, APIs, AI services, and the dashboard frontend |
| **analysis** | Contains all statistical analysis, machine learning experiments, and forecasting models used to support the application |
